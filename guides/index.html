How to use the guide library

If your country has a dedicated hub, start there first. A local hub gives you the fastest path because it connects the earning idea with the payout problem, the platform check, and the type of beginner route that fits that country.

If your country is not listed yet, use the general hubs by problem. Start with payout method survival when payment is the blocker, low minimum payout when you need a small proof, and task type reality when sites show too few tasks after signup.
