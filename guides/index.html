How to use the guide library

If you are new, do not open every article at once. Start with your main problem. If you do not know what works in your country, start with country first-payout routes. If your payment method is the problem, start with payout method survival guides. If you keep joining sites but seeing no tasks, start with task type reality guides.

The goal is not to make the guides look big. The goal is to help a beginner make a clean decision: which route is worth testing, which route should be avoided, and which payout method must be checked before doing work.
